OWASP #1

Girdi kutusuna doğrudan SQL komutları enjekte ederek kimlik doğrulamayı atlamayı deneyin.

// Üretilen Arka Plan SQL Sorgusu:
SELECT * FROM users WHERE username = 'admin' OR '1'='1' AND status='active';
Giriş Başarılı! (Admin Paneline Erişildi)
Güvenli Kodlama İlkesi (PDO / Prepared Statement): 
$stmt = $pdo->prepare('SELECT * FROM users WHERE username = :user');
$stmt->execute(['user' => $userInput]); // Parametrik Sorgu

RSA Asimetrik Şifreleme Mantığı

RSA algoritması iki büyük asal sayının (p, q) çarpımının zorluğuna ve Modüler Aritmetiğe dayanır.

1. Asal Sayılar: p = 61, q = 53
2. Modulus (n): n = p * q = 3233
3. Public Key (e, n): (e=17, n=3233) -> Herkese Açık
4. Private Key (d, n): (d=2753, n=3233) -> Gizli Tutulur
Şifreleme: C = M^e mod n | Şifre Çözme: M = C^d mod n

Python İle Basit Port Tarayıcı 

import socket

target = "192.168.1.1"
ports = [80, 443, 22]

for port in ports:
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(1.0)
    result = s.connect_ex((target, port))
    if result == 0:
        print(f"Port {port}: AÇIK")
    s.close()
